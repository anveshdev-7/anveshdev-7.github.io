About

About me

I'm Anvesh, a developer who creates modern, responsive and visually polished websites, and I care as much about how a page feels as how it looks.

Design with intent

Every page starts with what the visitor should see first. Typography, spacing and layout are built around that.

Build it properly

Clean, responsive code that loads quickly and works on phones, tablets and desktops.

Motion with purpose

Animation guides attention and adds polish. It never slows the page down, and it respects reduced-motion settings.
